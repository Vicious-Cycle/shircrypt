# Security Policy

## Reporting a Vulnerability

If you discover a cryptographic, memory-safety, or side-channel issue in `shircrypt`, please **do not** open a public GitHub issue.

Report it privately via [GitHub Security Advisories](https://github.com/Vicious-Cycle/shircrypt/security/advisories/new) with:
- Affected function and version
- Minimal reproduction or proof-of-concept
- Expected vs. actual behavior

We will acknowledge receipt within 48 hours and coordinate a fix before public disclosure.
